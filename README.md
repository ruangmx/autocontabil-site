# AutoContábil — Landing Page

Site institucional focado em automação operacional para escritórios de contabilidade.

🌐 **[autocontabil-site.vercel.app](https://autocontabil-site.vercel.app)**

---

## Sobre o projeto

Landing page desenvolvida para apresentar serviços de automação para contabilidades, com foco em eliminar retrabalho manual, erros de lançamento de tarefas e ineficiências no fluxo via WhatsApp → ERP.

O site é baseado em um case real onde a taxa de erro de identificação de clientes foi reduzida de 54% para praticamente zero após a implementação de automação com Context API + integração com Gestta/Onvio.

---

## Serviços apresentados

| Pacote | Descrição | Valor |
|---|---|---|
| Raio-X da Operação | Diagnóstico completo da operação | R$ 1.200 |
| Automação Pontual | Resolução de um processo manual | R$ 2.200 |
| Pacote Completo | Automação de ponta a ponta | A partir de R$ 3.500 |

## Deploy

O site é publicado automaticamente via Vercel a cada push na branch `main`.

```bash
# Clonar o repositório
git clone https://github.com/ruangmx/autocontabil-site.git

# Abrir no VS Code
cd autocontabil-site
code .
```
